# Hide My Email

Create iCloud Hide My Email addresses from Alfred with Apple's own sheet, using [NSHideMyEmail](https://github.com/gholts/NSHideMyEmail).

Type `hme <label>`, then click **Use** in Apple's sheet. The new address is copied to the clipboard.

## Build

`./build` builds `hme` from the latest [NSHideMyEmail](https://github.com/gholts/NSHideMyEmail) release tag and gives the workflow the same version. Set `NSHIDEMYEMAIL_VERSION` to build a specific release.
